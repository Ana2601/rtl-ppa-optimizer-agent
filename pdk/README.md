# sky130_fd_sc_hd timing library

`sky130_fd_sc_hd__tt_025C_1v80.lib.gz` is the typical-corner (25 °C, 1.80 V) Liberty file of
the SkyWater SKY130 high-density standard-cell library. It is taken unmodified from
[OpenROAD-flow-scripts](https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts/tree/master/flow/platforms/sky130hd/lib)
and gzipped. Licence: Apache 2.0 (SkyWater PDK, https://github.com/google/skywater-pdk).

`rtlopt/tools.py` decompresses it into `build/` on first use.
